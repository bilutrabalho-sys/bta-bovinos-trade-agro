# BTA 2.0 — DESIGN SYSTEM + FRONT-END VISUAL + PROTÓTIPO

## OBJETIVO

Criar no Figma o projeto completo de design e protótipo navegável do aplicativo **BTA — Bovinos Trade Agro**.

O BTA é uma plataforma digital de pecuária que combina:

* marketplace de bovinos;
* compra e venda;
* BTA Match;
* radar de oportunidades;
* inteligência de mercado;
* simuladores;
* gestão de negócios;
* educação;
* IA;
* análise de risco;
* logística;
* perfil profissional de fazendas.

O produto NÃO deve parecer um aplicativo comum de classificados.

Deve parecer uma **Agritech global de alto nível**, combinando a sofisticação visual de fintechs, marketplaces e plataformas SaaS com uma identidade própria do agronegócio.

## OBJETIVO DA PRIMEIRA VERSÃO

Criar somente a camada visual/prototipada.

Não criar:

* backend;
* banco de dados real;
* API;
* autenticação real;
* pagamentos reais;
* integrações externas.

Todos os dados devem ser **FICTÍCIOS / MOCKADOS**.

O protótipo deve, entretanto, parecer um aplicativo real e funcional.
